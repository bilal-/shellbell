Add registered local web Pages over the encrypted direct route, with trusted
registration files, shared on-demand process lifetimes, per-phone sign-in and
bounded icon delivery. Sous can register its existing web board without a
Shellbell-specific server protocol. Android has the first Pages client; iOS
remains disabled pending its native transport.

Add a headless plugin browser and Shellbell-owned registry of pinned public GitHub
provider packages. Sous owns its declarative manifest and icon in its repository;
Shellbell installs the integration only when Sous is already installed.
